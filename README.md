A full-featured e-commerce web application called GreatKart built with Django, designed to provide a seamless shopping experience similar to Flipkart.

🚀 Features
    User Authentication: Secure Sign-up, Login, and Logout functionality.

    Product Catalog: Browse products by categories with dynamic filtering.

    Search Functionality: Quickly find products using the search bar.

    Shopping Cart: Add, remove, and update item quantities in real-time.

    Order Management: Track order history and status.

    Responsive Design: Optimized for both desktop and mobile viewing.

    Admin Dashboard: Full CRUD (Create, Read, Update, Delete) capabilities for products, categories, and orders.

🛠️ Tech Stack
    Backend: Django (Python)

    Database: SQLite (Default)

    Frontend: HTML5, CSS3 (Bootstrap), JavaScript

    Tools: Django Templating Engine, Pillow (for image processing)
